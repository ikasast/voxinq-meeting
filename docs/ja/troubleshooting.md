# 困ったとき・FAQ

症状別の対処とよくある質問。 [← 日本語ガイドに戻る](../../README.ja.md)

## 困ったときは

### 文字起こしが始まらない

初回はWhisperモデルの読み込みに1分ほどかかります。音声は裏で保持されているので、**待てば反映されます**。
それでも進まない場合は、GPUのVRAMが空いているか確認してください。

そもそも会議中に文字が出ない設定になっている場合もあります → 次項。

### 録音が空だった（ほとんど何も入っていない）

**次の会議の前にマイクチェックを実行してください。** 録音ボタンの上のパネルで、音が届いているか
だけを数秒で確かめられます。会議を1つ失わずに確認できる方法はこれだけです。よくある原因は外から
見るとすべて同じに見えます:

- ミュートスイッチ付きのヘッドセットが、ミュートのまま
- OS が勝手に切り替えた入力（ドック接続、蓋を閉じた、通話が終わった）
- 別のアプリがマイクを排他的に掴んでいる
- 選択中のデバイスが違い、誰もいない部屋を録っていた

チェックで「音が届いている」と出るのに文字起こしが空の場合は、その先の問題です（次項以降）。

> チェックで開いたマイクはそのまま録音に引き渡されるので、**確認したものがそのまま録音されます**。
> 後からソースやマイクモードを変えると、要求する設定が変わるため確認結果は破棄されます。

### 録音中に文字が出ない

**状態表示の横に「録音のみ」と出ていませんか。** それは録音開始時にそう選んだ場合です
（他の処理が GPU を使っていたので、そのままにする方を選んだ）。**音声は保存されており、
会議を終了した時点で文字起こしされます**ので、何も失われていません。いったん終了して録り直す
必要はありません（録音が分割されるだけです）。

そうでなければ、録音ボタンの横の表示を見てください。**「● 会議の終了後に文字起こしします」**と出ていれば
故障ではなく仕様です。GPU 加速が無い機器では認識が発話より遅く、追いつこうとすると遅れ続けるため、
**録音だけ行って終了時に全体を一度で文字起こし**します。文字は会議終了後に出ます（CUDA 機と
完全に同じ文字起こしにはなりません → [GPU の種類による違い](setup.md#gpu-の種類による違い)）。
どの機器がどちらになるかは [GPU の種類による違い](setup.md#gpu-の種類による違い) を参照してください。

「● モデル準備完了」と出ているのに文字が出ない場合は別の問題です（次項）。

### キューが動かない

上部メニューの **順番待ち** を開くと、何が実行中で何が待っているかが分かります。何時間も
実行中のままの処理はそこで **停止** できます。

何も実行中でないのに何も始まらない場合、GPU を掴んだままのものがあります。**録音中の会議も
キューに出ます**（会議中に大きな処理が始まらないようにするため）。これは会議終了時・録音画面を
離れたとき・タブを閉じたときに解放されますが、**ブラウザが強制終了した場合やスマホがタブを
破棄した場合は解放されません**。そのため 30 秒ごとに STT サービスへ「どの会議が実際に接続中か」
を問い合わせ、接続の無いものから GPU を回収します（開始 90 秒以内のものは対象外です。予約は
WebSocket 接続より先に取るため）。

この回収には STT サービスが必要です。**到達できないときは何も解放しません**（「聞けなかった」は
「録音していない」ではないため）。STT が長時間落ちていると予約が残ることがあります。
`curl http://127.0.0.1:8000/health` で確認し、復旧すれば 1 分以内に解消します。

GPU が空いているのに待機中のままの処理は、**予算より大きい**可能性があります。その場合でも
単独では実行されますが、他と同時には走りません（`vramBudgetMb`）。

### 議事録の生成に失敗する

会議画面に**失敗の理由が表示されます**。よくある原因は:

- 「Cannot reach Ollama」→ Ollamaが起動していない、または設定のURLが違う
- 「API キーが未設定です」→ クラウドAIを選んでいるのにAPIキーが未設定
- **まとめて作成**でほとんどが「fetch failed (Headers Timeout Error)」→ 3.8.0 以前は全件が同時に
  始まり、モデルの順番待ちが 5 分を超えた分が打ち切られていました。3.8.1 からは 1 件ずつ実行されるので、
  もう一度まとめて作成してください

原因を直したら **Retry** ボタンで再実行できます。

### 議事録が「生成中」のまま戻らない

一覧が「議事録を生成中」のままで、詳細画面の**停止**を押しても変わらず、**まとめて作成**の
対象にもならない状態です。3.8.1 までは、**まだ始まっていない**議事録ジョブをキュー画面から
止めると、この状態から戻れませんでした（議事録は1件ずつ実行されるので、まとめて依頼した分の
ほとんどは「待機中」です）。それより後の版では、サーバー起動後30秒以内にキューと突き合わせて
自動的に戻し、「議事録なし」として再度まとめて作成できるようになります。

### 議事録に会議で話していない内容が混ざる

「業務背景情報」に書いた内容が混入している可能性があります。**背景情報は簡潔に**書いてください。

### スマホから開くと画面が真っ白／反応しない

開発モード（`npm run dev`）で起動している可能性があります。`scripts/start` で本番ビルドとして起動してください。

### Android アプリが更新できない／つながらない／通知が来ない

- **更新できない（「アプリはインストールされていません」）** — 入っているのが開発版で、署名が違います。
  **先にサーバーにつながる状態で古いアプリを一度開いて**（未送信の音声を送るため）、アンインストール
  してから入れ直してください
- **ブラウザでは開けるのにアプリだけつながらない** — アプリは **https のみ**です。`http://` のアドレスでは
  なく `https://<ホスト名>.<テイルネット名>.ts.net` を入れ、スマホの Tailscale がつながっているか確認してください
- **予約の通知が来ない** — アプリの通知（または「会議のリマインド」だけ）がオフになっていないか。
  アプリが 3.8.5 以前だと、**アプリを開いたときにしか通知が来ない**ことがあります（予約をスマホが知る
  機会が、アプリを開いたときしか無かったため。3.8.6 で修正）。3.8.3 以前は、通知が最大 1 時間遅れることも
  ありました。3.8.6 でも、別の端末で開始の数分前に入れた予定は、次の確認（15 分おき）まで届かないことが
  あります。アプリを一度開けばすぐ設定されます。サーバーが 3.8.0 より古いと届きません
- **共有が「HTTP 404」で失敗する** — サーバーが 3.8.0 より古いです

より詳しい対処法は [docs/troubleshooting.md](../troubleshooting.md)（英語）にまとめています。

## よくある質問（FAQ）

**Q. 本当に外部に何も送信されませんか？**
初期設定のままなら、音声・発言ログ・議事録はすべてPC内で処理されます。外に出る経路は
**2つあり、どちらも既定では使いません**。

1. **議事録のLLM** — Anthropic や OpenAI を選ぶと、**発言ログ（テキスト）**が送られます
2. **文字起こしのエンドポイント** — Groq・Gemini などを登録して選ぶと、**音声そのもの**が
   送られます。テキストではなく音声なので、こちらは実行のたびに選ぶ形にしてあり、確認ダイアログと
   設定画面に送信先のホスト名が出ます

**声紋とデータベースは、どちらを使っていても外に出ません。**送る経路がありません。

**Q. 録音データはどれくらい保存されますか？**
音声ファイル（WAV）は**7日で自動削除**されます。残したい場合は会議画面で「保護する」を押してください。
発言ログと議事録はデータベースに残るので、削除しない限り消えません。

**Q. GPUがないPCでも動きますか？**
動きます。v2.0 から、機器に合わせてエンジンが選ばれるようになりました。変わるのは
**文字が出るタイミング**だけです — GPU 加速のある機器は会議中に、無い機器は会議終了時に
まとめて文字起こしします。モデルも精度も同じで、議事録生成・話者分離・検索はそのまま使えます。
詳しくは [GPU の種類による違い](setup.md#gpu-の種類による違い) を参照してください。

**Q. 日本語以外にも対応していますか？**
Whisperが多言語対応なので、話す言語は自動判定されます。議事録の出力言語は日本語・英語・中国語から選べます。

**Q. 複数人で使えますか？**
**使えます**（v3.1 から）。一人がアカウントを作ると、そのサーバーはアカウント制に切り替わります。
会議・議事録・声紋・設定は各自のもので、**管理者にも他人の会議は見えません**。
発言と議事録は本人の鍵で暗号化されます。→ [複数人で使う](security.md#複数人で使うアカウント)

ただし**計算資源は1つのまま**です。文字起こし・話者分離・議事録生成はどれも GPU（または CPU）を
占有するので、同時には走りません。**サーバー側のキューが順番に処理します** — 5人が同時に押しても
失敗はせず、順番待ちになるだけです。キューでは各行が誰のものかは見えますが、**何の会議かは
見えません**。

同時に**録音**することはできます（録音は取り込むだけで、重い処理は終了後です）。ただし
GPU を使うライブ文字起こしは録音が優先で、走っていた処理は中断されて後で再開します。

**Q. スマホで録音中に画面を消しても大丈夫ですか？**
録音中は**アプリ側で画面が自動的に消えないようにしています**（Wake Lock）。
ただし次の場合は効かないので注意してください。

- **電源ボタンで手動でロックした場合** — 端末によってはマイクが停止します
- **HTTPSでない接続の場合** — Wake LockはHTTPS（またはlocalhost）でのみ動作します。
  Tailscale経由（`https://`）なら有効です

万一切断されても**自動で再接続し、切断中の音声も保持して復帰後に送信する**仕組みが入っていますが、
念のため**画面は点けたままにしておくのが確実**です。

電池が気になる場合は、**画面を真っ暗にしたまま録音を続ける「休止画面」**が使えます。上のバーの
**画面を消す**、または **設定 → 表示** で無操作から 30秒〜10分後に自動で切り替わります。
画面ロックもマイクもアップロードも動いたままなので**録音は止まりません**（経過時間が動き続けるのが
その証拠です）。有機ELでは黒い画素が光らないぶん効果が大きく、液晶では限定的です。

**Q. 会議中にPCの音声（オンライン会議）も録音できますか？**
できます。録音ソースで「PC音声」または「マイク + PC音声」を選んでください。
※「両方」の場合はヘッドホンの使用を推奨します（スピーカーだと二重に録音されます）。

**Q. スマホのアプリはありますか？**

Android にはあります（v3.8.0 から Releases に APK）。ブラウザではできない**画面を消したままの録音**が
でき、予約の通知と共有からの取り込みも付きます → [Android アプリ](setup.md#android-アプリ画面を消しても録音が続く)。
iOS は ReplayKit と有料の開発者アカウントが要るため作っていません。PWA で使ってください。

**Q. スマホで参加している通話・オンライン会議を録音できますか？**

スマホでは録音ソースに「PC音声」が出ません。**出せません** — 画面共有 API
（`getDisplayMedia`）はモバイルブラウザに一つも実装されておらず（Chrome for Android /
Safari / Samsung Internet / Firefox すべて未対応）、Web ページから他アプリの音声に
到達する方法が存在しないためです。

代わりに**スピーカーホン**を使います。ただし**先に設定を 1 つ変える必要があります**。

1. **設定 → マイクモード → Room（離れた声も拾う）**
2. 通話をスピーカーホンにして、録音ソースは **マイク** のまま録音する

Room は 2 つのことをしていて、距離の話はそのうち片方です。**取り込む音量を 4 倍に上げる**のがもう
片方で、話し手が耳元ではなくテーブルの向こうにいるときに効くのはこちらです。エコーの話に戻ると、
通常モードではブラウザのエコーキャンセルが
有効で、その役目は**自分の端末のスピーカーから出ている音をマイク入力から取り除くこと**です。
スピーカーホン通話では、それがそのまま**相手の声**にあたります。通常モードで録ると、
自分の声だけが残り、相手の声が黙って消えます。Room モードはエコーキャンセルを切るので、
両方が録音されます。

音質はスピーカーとマイクを経由するぶん直接取り込みには劣りますが、文字起こしには十分使えます。

> 通話の音声は、ネイティブアプリでも直接は録れません。Android で他のアプリの音声を取り込む仕組み
> （MediaProjection）の対象は音楽・動画などの再生音だけで、電話や Zoom・Teams・Meet などの通話の
> 音声はプライバシー保護のため対象外です。iOS はそもそも ReplayKit と有料の開発者アカウント
> （年 $99）が要ります。通話の録音は、上のスピーカーホン＋Room の方法が唯一の手段です。
