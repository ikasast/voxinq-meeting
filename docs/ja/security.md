# セキュリティと外部公開

何が外に出るか、アカウントと暗号化、Tailscale の外からの閲覧。 [← 日本語ガイドに戻る](../../README.ja.md)

## 何が外に出るか

**既定では外部APIを一切使いません。** APIキーも、月額料金も不要です。

外に出る経路は**2つだけ**で、どちらも既定では使いません。

- **議事録を作るLLM** — 希望すれば Anthropic や OpenAI に切り替えられます（文字起こし済みの
  テキストが送られます）
- **文字起こし** — Groq・OpenAI・Google Gemini などの保存済みエンドポイントに送れます。
  こちらは**テキストではなく音声そのもの**が送られるので、実行のたびに選ぶ形にしてあり、
  確認ダイアログと設定画面に送信先のホスト名を表示します

**声紋とデータベースは、設定に関わらず外に出ません。**送る経路がそもそもありません。
どちらの切り替えもしない限り、何も外には出ません。

## 複数人で使う（アカウント）

誰かがアカウントを作るまで、このアプリは従来どおりです — 共有パスワード1つ（または無し）で、
到達できる人には全部見えます。**何も変わりません。**

**最初のアカウントを作る**（ログイン画面からリンクされている `/setup`）とサーバーが切り替わります。
そのアカウントは管理者で、既存の会議は全てそのアカウントのものになり、`APP_PASSWORD` は入口では
なくなります。

以後、本人であることの示し方は 2 つです。

- **メールアドレスとパスワード** — tailnet の外から入るときに入力します
- **tailnet のログイン** — tailnet の内側では既に本人確認が済んでいるので、改めて聞きません。
  初めて見る ID は、初回アクセス時にアカウントになります

この 2 つは地続きです。**tailnet のログインはメールアドレスそのもの**なので、後者で作られた
アカウントにも最初からアドレスが入っており、パスワードさえ設定すれば外からも入れます。
**自分の名前 → Account** で設定してください。同じ画面で表示名とアカウント画像も設定できます —
キューで他の人に見えるのはこれです。

**このアドレスには何も送られません。** このサーバーにメールを送る手段は無く、持たせるつもりも
ありません。アドレスは「どのアカウントか」を言うための名前であって、連絡先ではありません。
だから打ち間違えても致命的ではなく、管理者のリセットリンクは変わらず使えますし、Account 画面で
直せます。

アカウントには短い**ユーザー名**（`sam`、埋まっていれば `sam2`）も付きますが、入力する場面は
ありません。アカウント画像の配信 URL に使われるのと、表示名を設定していないときに表示される名前
です。

### 自分のものと、そうでないもの

会議・発言・議事録・録音・声紋・キューは自分のものです。**管理者にも見えません** — 他人の会議を
開こうとすると「拒否」ではなく「見つかりません」になります。存在するかどうかも伝えるべきでは
ないからです。

**キューだけは例外**で、これは意図的です。GPU は 1 つの共有物なので、「自分の処理がなぜ始まらないか」
は、その理由が抜けた一覧では答えられません。他人の行については**誰のものか・どの種類の処理か**が
見え、**何の会議かは見えません**。

### 管理者の場合

**メンバー**（レールとアカウントメニュー）でアカウントの作成・無効化・管理者権限の付与ができます。
各人の会議「件数」は出ますが、これはディスクが埋まっていることを示すだけで、中身は何も示しません。

- **アカウントは無効化するもので、削除しません。** アカウントは会議を保持しているので、削除は
  「消す」か「部屋にいなかった人に渡す」のどちらかにしかなりません。無効化はセッションも即座に
  終了し、元に戻せます
- **管理者はパスワードを設定できません。** 15分有効のワンタイムリンクを発行して手渡します。
  パスワードを設定できる管理者は、気づかなかった人の議事録を読めてしまいます
- 最後の管理者は降格も無効化もできず、自分自身も無効化できません
- 他人のキュー行の並べ替え・停止はできます。中身は見えないままです

`VOXINQ_SIGNUP=closed` でアカウント作成そのものを止められます（→ [設定](setup.md#ファイルで設定するものenv)）。

## 暗号化と復旧コード

パスワードを持つアカウントには鍵があり、**発言と議事録が暗号化**されます。タイトル・日付・タグは
暗号化しません — 一覧・カレンダー・検索バーはそれで出来ているためです。

**復旧コードは1度しか表示されません。** パスワードを忘れたときに自分の会議へ戻る唯一の手段で、
どこにも保存されません。管理者はパスワード再設定のリンクを送れますが、**このコードが無ければ、
その新しいパスワードで開くのは「昔の会議が読めないアカウント」**です。パスワードマネージャに
入れてください（紙でも構いません。読み間違えやすい文字は使っていません）。

パスワードのリセット時にはこのコードを聞かれます。入力すれば全て保たれます。「持っていない」を
選んだ場合は、**何を失うのかを明示したうえで**確認します。

**守れるもの**: 盗まれたディスク、DB ダンプ、バックアップファイル、管理者が行を直接覗く場合。

**守れないもの**: 稼働中のサーバーを掌握した相手。鍵は「アプリを使っている間」と「キューに仕事が
ある間」開いています — 議事録は会議の後、多くはブラウザを閉じた後に書かれ、その処理は会議を読める
必要があるためです。

**ログアウトすると、その場で閉じます。** 離れる機械では、これが「隠す」ではなく「読めなくする」
操作にあたります。誰もログインしておらず、キューも空で、15分使われなければ鍵は破棄されます。

tailnet の内側では何も入力せずに本人と分かりますが、**その ID は鍵を開ける秘密を持っていません**。
そのため、鍵が閉じた状態で開くと画面上部に **Your meetings are locked** と出て、パスワードを 1 回
だけ聞きます。これは「誰か」を聞いているのではなく（それは分かっています）、開ける物を受け取る
ためのものです。

`VOXINQ_KEY_SECRET` を設定してください。これがあると、**DB だけを盗まれても開いた鍵は読めません**
（→ [設定](setup.md#ファイルで設定するものenv)）。

### 暗号化された会議の検索

検索は従来どおり動き、見つかるものも同じです。内部では、暗号化された会議は「読む」のではなく
**鍵付きハッシュの索引**で見つけ、サーバーは言葉を持たないまま照合してから、候補だけを復号して
スニペットを作ります。

ここから 2 つ帰結します。**録音中の会議は終了するまで検索に出ません**（索引は終了時に作られます）。
そして**1文字の検索は索引を使えず**、タイトル照合にフォールバックします。

索引は無料ではありません。DB を持つ相手には「各会議が持つ相異なる2文字列の数」と「どの会議が共有
しているか」が見えます。言葉ではなく、鍵が無ければ戻せませんが、ゼロではありません — 検索が
成立しているのはこの代償の上です。

## Tailscale の外から「閲覧・ダウンロードだけ」共有する

Tailscaleを入れられない端末（会社のPCなど）にも議事録を見せたいときは、**Tailscale Funnel**
でWebアプリだけを公開し、`.env` に `APP_PASSWORD`（と強い `APP_SESSION_SECRET`）を設定します。
外部からのアクセスは自動で**閲覧・ダウンロードと会議の準備だけ**になります。会議の作成・予約と、
タイトル・目的と議題・タグ・参加者・シリーズの編集、シリーズの共通設定（背景・常任メンバーなど）は
外からもできます。録音・議事録の生成・発言の編集・話者分離・削除・設定の変更はサーバー側で
拒否されます（HTTP 403）。tailnet内の端末は従来どおり全機能を使えます。

公開/非公開の切り替えは、tailnet接続の端末から **設定 → 外部公開** でワンクリック
できます（内部で `tailscale funnel`／`serve` を実行）。外部の閲覧者にはこのトグルは表示されず、
操作もできません。

> ⚠️ 公開するのは **Webアプリ（443）だけ**にしてください。文字起こしサービス（8443）は認証が
> ないため、絶対にFunnelで公開しないこと。詳細は [docs/remote-access.md](../remote-access.md)（英語）へ。

## Tailscale を使いたくない場合

自前の **WireGuard**（Tailscaleの中身と同じVPN）など、Tailscale以外の方法でも外部アクセスできます。
ただし Tailscale が自動でやっていたこと（HTTPS証明書の発行・文字起こしサービスの公開・内部判定）を
手動で用意する必要があり、**閲覧だけなら簡単・録音までやるなら追加の手間**がかかります。
各方式の比較と手順は **[docs/remote-access.md](../remote-access.md)（英語）** にまとめています。
